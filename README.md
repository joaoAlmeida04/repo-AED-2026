# Algoritmos e Estruturas de Dados em C# ⚙️

Repositório dedicado à implementação manual e estudo profundo de estruturas de dados e algoritmos de ordenação, construídos em C# para uma compreensão aprofundada do funcionamento interno das estruturas e de suas complexidades.

## 🧠 Tópicos Abordados

*   **Listas Lineares e Duplamente Encadeadas:** Implementação de nós, alocação dinâmica e manipulação de ponteiros.
*   **Pilhas (Stacks) e Filas (Queues):** Estruturação LIFO e FIFO clássicas, incluindo filas flexíveis.
*   **Algoritmos de Ordenação (MergeSort):** Implementação de divisão e conquista, com análise de contagem de operações matemáticas para a função de complexidade $f(n)$.
*   **Recursividade:** Métodos recursivos para manipulação de strings e arrays.

## 📂 Estrutura do Projeto
Cada diretório agrupa implementações baseadas em listas de exercícios propostas em sala, com o objetivo de aplicar na prática a lógica das estruturas de dados e os métodos de ordenação.

## 🛠️ Tecnologias
- C# (.NET)
- Visual Studio / VS Code
